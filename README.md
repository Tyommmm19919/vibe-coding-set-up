# Vibe Coding Setup

A ready-to-use **Symfony 6.4 + Sonata Admin** starter project designed for AI-assisted development (vibe coding).

Includes authentication, database configuration, an admin panel, CRUD operations, file uploads, and essential configurations—allowing you to focus on building features instead of setting up the project from scratch.

## Front-End

A flexible foundation for building complex, interactive user interfaces.

The architecture keeps CSS and JavaScript organized into separate, manageable files, making it easier for AI to navigate, understand, and modify the codebase.

The goal is simple: **AI-generated code that remains clean, structured, and understandable for human developers.**

## Back-End

Back-end development is often one of the biggest challenges in vibe coding.

This setup uses **PHP with Symfony 6.4**, making deployment and server-side development more straightforward.

Unlike Python frameworks such as FastAPI, which typically require a separate running application server, PHP applications can be executed directly through a compatible web server.

This makes it convenient to develop with AI, push changes to GitHub, and deploy them to your hosting environment without managing a separate Python application process.

## Sonata Admin

The project already includes the foundation of **Sonata Admin**, a powerful administration framework for Symfony.

Setting up Sonata Admin from scratch can be challenging, especially when relying heavily on AI-generated code.

By providing a working foundation, this repository allows AI to build on an existing structure, add new entities, create CRUD interfaces, and extend the admin panel with additional functionality.

## Workflow

Getting started is simple:

1. **Download or clone** this repository.
2. **Add the project** to your own GitHub repository.
3. **Configure the database** and environment variables in your local `.env` configuration.
4. **Set up deployment** to your website's server files.
5. **Connect your AI coding tool** to the repository and start developing.

Once everything is configured, AI can work directly on your project, create new features, and modify existing code.

All you need to do is **review, push, and deploy the changes.**
